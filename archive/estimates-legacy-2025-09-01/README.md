# Архив Legacy версии системы смет

Дата архивирования: 2025-09-01

## 📦 Содержимое архива

### Страницы (legacy версия):
- `estimates/EstimateEditorPage.tsx` - старый редактор смет
- `estimates/MobileEstimatePage.tsx` - старая мобильная версия смет  
- `estimates/ProjectEstimatesPage.tsx` - старая страница смет проекта

### Типы данных:
- `estimate.ts` - старые типы для смет

### Тестовые файлы:
- `mobileEstimate.test.tsx` - тесты для старой мобильной версии

## 🔄 Причина архивирования

Эти файлы были заменены новой архитектурой смет:

### Новые компоненты (актуальные):
- `/src/pages/estimates/EstimatesHub.tsx` - главная страница смет
- `/src/pages/estimates/EstimateConstructor.tsx` - конструктор смет с блочной архитектурой
- `/src/pages/estimates/QuickEstimateCreate.tsx` - быстрое создание смет
- `/src/components/estimates/SwipeableEstimateCard.tsx` - карточки со свайп-жестами
- `/src/components/estimates/TouchOptimizedEstimateForm.tsx` - touch-оптимизированная форма

### Новые API:
- `/src/api/estimateV2Api.ts` - новый API для работы со сметами
- `/src/api/estimateV2StreamApi.ts` - стрим API для real-time обновлений
- `/src/types/estimate.types.ts` - новые типы с блочной архитектурой

## 🏗️ Ключевые отличия новой версии

### Блочная архитектура
Новые сметы состоят из 7 независимых блоков:
1. **Контрагент** - выбор клиента и контактного лица
2. **Проект** - привязка к проекту и локации  
3. **Услуги** - добавление работ и услуг
4. **Товары** - добавление материалов и оборудования
5. **Себестоимость** - настройка расчетов и маржи
6. **Коммуникация** - настройка взаимодействия с клиентом
7. **Статусы** - управление жизненным циклом сметы

### Улучшенная мобильная адаптация
- Свайп-жесты для быстрых действий
- Touch-оптимизированные элементы управления
- Адаптивные breakpoints для всех размеров экранов
- Modern UX паттерны

### Расширенные статусы
```
draft → internal_review → sent → viewed → 
negotiation → accepted/rejected → converted/canceled
```

### Real-time синхронизация
- Автоматическое обновление данных
- Совместная работа над сметами
- Отслеживание изменений

## 🚨 Важные заметки

1. **Legacy API сохранен** - `/src/legacy/api/estimateApi.ts` остается для QuickEstimateCreate
2. **Миграция данных** - старые сметы автоматически мигрируют в новый формат
3. **Обратная совместимость** - данные старых смет читаются новой системой

## 📚 Связанные изменения

### Удаленные зависимости:
- Импорты из `../legacy/estimates/MobileEstimatePage`
- Импорты из `../types/estimate.ts` 
- Тесты старой мобильной версии

### Обновленные импорты:
- Все новые компоненты используют `/src/types/estimate.types.ts`
- API вызовы используют `estimateV2Api.ts` и `estimateV2StreamApi.ts`

## 🔧 Восстановление из архива

Если необходимо восстановить legacy код:

1. Скопировать файлы обратно в исходные локации
2. Восстановить импорты в зависимых файлах  
3. Добавить обратно роуты в `AppRouter.tsx`

⚠️ **Внимание**: При восстановлении legacy кода могут возникнуть конфликты с новой архитектурой.
