# ✅ Чек-лист мануального тестирования Startability System

**Тестовая страница:** http://localhost:3000/startability-v2-test

---

## 🚀 Быстрый старт

1. Убедитесь что dev сервер запущен:
   ```bash
   npm start
   ```

2. Откройте браузер:
   ```
   http://localhost:3000/startability-v2-test
   ```

3. (Опционально) Включите feature flag в консоли браузера:
   ```javascript
   localStorage.setItem('feature_estimates.startability_v1', 'true')
   ```

---

## 📋 Основные тесты

### ✅ Тест 1: Визуальная проверка Master Grid

**Цель:** Убедиться что таблица проектов отображается корректно

- [ ] Таблица загружается и отображается
- [ ] Видны колонки: Проект, Статус, Стартуемость, Действия
- [ ] Индикаторы стартуемости отображаются цветом:
  - 🟢 Зеленый = готов к старту
  - 🟡 Желтый = предупреждение
  - 🔴 Красный = заблокирован
- [ ] Можно прокручивать список проектов

**Ожидаемый результат:** Все элементы видны и читаемы

---

### ✅ Тест 2: Открытие Detail Sidebar

**Цель:** Проверить работу боковой панели с деталями

**Шаги:**
1. Найдите в таблице проект с красным индикатором 🔴
2. Кликните на кнопку "Детали" или на строку проекта
3. Боковая панель должна открыться справа

**Проверить:**
- [ ] Sidebar открывается плавной анимацией
- [ ] Отображается название проекта
- [ ] Показан общий статус стартуемости
- [ ] Перечислены все причины блокировки
- [ ] Причины сгруппированы по категориям
- [ ] Видны иконки причин (🚫, 📝, 💰, 👤, etc.)
- [ ] Есть кнопка закрытия (X) в правом верхнем углу

**Ожидаемый результат:** Sidebar работает корректно

---

### ✅ Тест 3: Проверка кодов причин

**Цель:** Убедиться что все типы блокировок корректно отображаются

**Найдите проекты со следующими причинами:**

- [ ] 🚫 **PROJECT_STATUS_NOT_STARTABLE**
  - Текст: "Статус проекта не допускает старт"
  - Найти проект со статусом "completed" или "cancelled"

- [ ] ⏸️ **PROJECT_ON_HOLD**
  - Текст: "Проект на удержании (on hold)"
  - Найти проект со статусом "on_hold"

- [ ] 📝 **NO_TASKS**
  - Текст: "Нет задач в проекте"
  - Проект без задач

- [ ] 🔒 **ALL_TASKS_BLOCKED**
  - Текст: "Все задачи недоступны для старта"
  - Все задачи в статусах: done, blocked, cancelled

- [ ] 💰 **NO_ESTIMATES**
  - Текст: "Нет смет"
  - Проект без смет

- [ ] 👤 **MISSING_ASSIGNMENT**
  - Текст: "Нет назначенного исполнителя/команды"
  - Задачи без assigneeId

**Ожидаемый результат:** Все причины отображаются с правильными иконками и текстом

---

### ✅ Тест 4: Actionable Components

**Цель:** Проверить работу компонентов для решения проблем

**Шаги:**
1. Откройте Sidebar для проекта с блокировкой "Нет исполнителя"
2. Найдите секцию "Действия для разблокировки"
3. Должна быть кнопка "Назначить исполнителя"

**Проверить для разных типов блокировок:**

- [ ] **Нет исполнителя** → Кнопка "Назначить исполнителя"
- [ ] **Нет сметы** → Кнопка "Создать смету"
- [ ] **Требуется утверждение** → Кнопка "Запросить утверждение"
- [ ] **Неправильный статус** → Кнопка "Изменить статус"

**Ожидаемый результат:** Для каждой блокировки есть действие

---

### ✅ Тест 5: Фильтрация

**Цель:** Проверить работу фильтров

**Шаги:**
1. Найдите переключатель режимов просмотра
2. Переключите на "Только заблокированные"
3. Переключите на "Только доступные"
4. Переключите обратно на "Все проекты"

**Проверить:**
- [ ] Фильтр "Только заблокированные" показывает только проекты с 🔴
- [ ] Фильтр "Только доступные" показывает только проекты с 🟢
- [ ] Фильтр "Все проекты" показывает все
- [ ] Счетчик показывает правильное количество проектов
- [ ] Переключение работает без перезагрузки страницы

**Ожидаемый результат:** Фильтры работают корректно

---

### ✅ Тест 6: Сортировка

**Цель:** Проверить сортировку по стартуемости

**Шаги:**
1. Посмотрите на порядок проектов в таблице
2. Убедитесь что сортировка следующая:
   - Сначала стартуемые (🟢)
   - Затем с предупреждениями (🟡)
   - В конце заблокированные (🔴)

**Проверить:**
- [ ] Зеленые проекты в начале списка
- [ ] Красные проекты в конце списка
- [ ] Внутри каждой группы сортировка по дате (свежие сначала)

**Ожидаемый результат:** Сортировка логичная и полезная

---

### ✅ Тест 7: Примеры заблокированных задач

**Цель:** Проверить отображение примеров задач

**Шаги:**
1. Откройте Sidebar для проекта с причиной "ALL_TASKS_BLOCKED"
2. Прокрутите до секции "Примеры заблокированных задач"

**Проверить:**
- [ ] Показаны до 3 примеров задач
- [ ] Для каждой задачи указан статус
- [ ] Для каждой задачи показано название
- [ ] Если задач > 3, показано "и еще X задач..."

**Ожидаемый результат:** Примеры помогают понять проблему

---

### ✅ Тест 8: Responsive Design

**Цель:** Проверить адаптивность на разных экранах

**Шаги:**
1. Откройте DevTools (F12)
2. Переключите на мобильное разрешение (375x667)
3. Проверьте на планшете (768x1024)
4. Проверьте на desktop (1920x1080)

**Проверить:**
- [ ] На мобильном Sidebar открывается на весь экран
- [ ] Таблица адаптируется под ширину экрана
- [ ] Все тексты читаемы
- [ ] Кнопки доступны для нажатия
- [ ] Нет горизонтальной прокрутки

**Ожидаемый результат:** UI корректен на всех разрешениях

---

### ✅ Тест 9: Производительность

**Цель:** Проверить что система работает быстро

**Проверить:**
- [ ] Таблица загружается < 2 секунд
- [ ] Sidebar открывается мгновенно (< 300ms)
- [ ] Фильтрация работает без задержек
- [ ] Нет лагов при прокрутке
- [ ] Smooth анимации

**Ожидаемый результат:** Все работает быстро и плавно

---

### ✅ Тест 10: Обработка ошибок

**Цель:** Проверить graceful degradation

**Сценарии:**
1. Отключите интернет
2. Обновите страницу
3. Проверьте что показывается

**Проверить:**
- [ ] Показывается сообщение об ошибке (не белый экран)
- [ ] Есть кнопка "Повторить попытку"
- [ ] После восстановления связи данные загружаются
- [ ] Нет критических ошибок в консоли

**Ожидаемый результат:** Ошибки обрабатываются корректно
