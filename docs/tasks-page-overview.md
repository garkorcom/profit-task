# Страница задач (`/tasks`)

## Назначение
- Управление личными задачами пользователя и учёт времени по ним
- Предоставление быстрых метрик (общее количество, завершённые, активные, процент выполнения)
- Быстрый фильтр по тексту, статусу, приоритету и проекту

## Стек и ключевые зависимости
- UI: Material UI (`Box`, `Card`, `Select`, `Fab`, `Chip`, `Dialog` и др.)
- Иконки: `@mui/icons-material` (например, `PlayArrow`, `Flag`, `Schedule`)
- Контексты: `useAuth` для текущего пользователя, `useTimeTracking` для интеграции с учётом времени
- API: `getTasksStream`, `addTask`, `updateTask`, `deleteTask` из `src/api/taskApi.ts`, `subscribeToProjects` из `src/api/projectV2Api.ts`

## Загрузка данных
- При монтировании компонента подписывается на две Firestore-коллекции:
  - `users/{uid}/tasks` — поток задач через `getTasksStream`
  - проекты пользователя через `subscribeToProjects`
- После получения проектов статус `loading` снимается
- Очистка подписок происходит в `useEffect` при размонтировании или смене пользователя

## Фильтрация и агрегация
- `useMemo` фильтрует задачи по поисковому запросу, статусу, приоритету и проекту
- Ещё один `useMemo` вычисляет статистику: количество задач, количество в работе, количество завершённых, процент выполнения

## Интерфейс
- Заголовок и кнопка «Новая задача» (недоступна, если нет проектов)
- Блок карточек статистики с аватарами и иконками
- Карточка с фильтрами (поиск, статус, приоритет, проект)
- Список карточек задач:
  - Название, описание, чипы статуса/приоритета/проекта/плана
  - Подсветка активной задачи (данные из `TimeTrackingContext`)
  - Кнопка редактирования (открывает диалог формы)
  - Кнопка удаления (открывает `ConfirmDialog`)
  - Кнопка учёта времени (`TimeTrackingButton`), если статус позволяет
- FAB «плавающая» кнопка создания

## CRUD и форма
- Диалог создания/редактирования синхронизирован с `formData`
- Валидация: требуется название и проект
- Сохранение вызывает `addTask` или `updateTask`
- Уведомления (`Notification`) отображают успех или ошибки операций
- Удаление задач через `deleteTask` после подтверждения

## Дополнительные аспекты
- Кастомная раскраска статусов и приоритетов (`getStatusInfo`, `getPriorityColor`)
- Поддержка дополнительных полей (вопросы, что купить, теги, плановое время, флаги фотофиксации)
- Firestore timestamps (`createdAt`, `updatedAt`) проставляются на стороне API
