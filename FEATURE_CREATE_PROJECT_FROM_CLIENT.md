# Функция: Создание проекта из карточки клиента

## Описание
Добавлена возможность создания проекта прямо из карточки контрагента (клиента). Это упрощает процесс создания проектов и автоматически связывает проект с клиентом.

## Где находится функция
- **Страница:** Контрагенты (`/contractors`)
- **Компонент:** `src/pages/ContractorsPage.tsx`

## Как это работает

### 1. Кнопка "Создать проект"
- Отображается только для контрагентов с типом "Клиент" или "Поставщик и клиент"
- Расположена в карточке контрагента под информацией о типе
- Имеет иконку папки и синий цвет (primary)

### 2. Диалог создания проекта
При нажатии на кнопку открывается диалог со следующими полями:
- **Название проекта** (обязательное поле)
- **Описание проекта** (многострочное текстовое поле)
- **Статус** (выпадающий список):
  - Планируется
  - Активный
  - Приостановлен
  - Завершен
- **Бюджет** (числовое поле с символом ₽)
- **Дата начала** (по умолчанию - текущая дата)
- **Дата окончания**

### 3. Автоматическая связь с клиентом
При создании проекта автоматически заполняются поля:
- `contractorId` - ID клиента
- `contractorName` - Название клиента

### 4. После создания проекта
- Показывается уведомление об успешном создании
- Происходит автоматический переход на страницу проектов
- Поля формы очищаются

## Технические детали

### Используемые API функции
```typescript
import { addProject } from '../api/projectApi';

// Создание проекта
await addProject(userId, {
  name: string,
  description: string,
  status: 'planned' | 'active' | 'paused' | 'completed',
  contractorId: string,
  contractorName: string,
  startDate: string,
  endDate?: string,
  budget: number
});
```

### Структура данных проекта
```typescript
interface Project {
  id: string;
  name: string;
  code?: string;
  description?: string;
  status?: ProjectStatus;
  startDate?: string;
  endDate?: string;
  contractorId?: string;
  contractorName?: string;
  budget?: number;
  estimatesCount?: number;
  createdAt?: any;
  updatedAt?: any;
}
```

## Обработка ошибок
- Если название проекта не заполнено, кнопка "Создать проект" неактивна
- При ошибке создания проекта показывается уведомление с сообщением об ошибке
- Ошибка логируется в консоль для отладки

## Улучшения UX
1. **Автозаполнение:** Если название проекта не указано, используется шаблон "Проект для [Имя клиента]"
2. **Визуальная обратная связь:** Используются уведомления для информирования о результате операции
3. **Быстрый доступ:** Кнопка доступна прямо из карточки, не нужно переходить на другие страницы
4. **Контекстная информация:** В заголовке диалога отображается имя клиента

## Права доступа
- Функция доступна только авторизованным пользователям
- Проект создается в коллекции пользователя (`users/{userId}/projects`)

## Связанные компоненты
- `ContractorsPage` - страница контрагентов
- `ProjectsPage` - страница проектов (куда происходит переход после создания)
- `projectApi` - API для работы с проектами
- `Notification` - компонент уведомлений
- `Dialog` - Material-UI диалог
