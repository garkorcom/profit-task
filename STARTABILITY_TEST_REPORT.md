## ⚠️ Выявленные проблемы

### 1. Отсутствует экспорт функции `isTaskStatusBlocked`
**Статус:** ⚠️ Незначительная проблема
**Решение:** Использовать `isTaskStatusStartable` вместо `isTaskStatusBlocked`

```javascript
// Доступно:
export function isTaskStatusStartable(status?: string): boolean

// Отсутствует:
// export function isTaskStatusBlocked(status?: string): boolean
```

### 2. Функция `canStartWorkDetailed` требует параметр `project`
**Статус:** ⚠️ Требует корректировки тестов
**Сигнатура:**
```javascript
canStartWorkDetailed(task: Task, project: Project): TaskStartability
```

**Проблема в тестах:**
```javascript
// ❌ Неправильно:
canStartWorkDetailed(task)

// ✅ Правильно:
canStartWorkDetailed(task, project)
```

### 3. Логика определения стартуемости
**Статус:** 🔍 Требует дополнительной проверки

Проект с активным статусом, задачами и сметами все равно может быть заблокирован, если:
- Задачи не имеют исполнителя (`assigneeId`)
- Есть compliance hold
- Требуется утверждение

**Рекомендация:** Это корректное поведение, тесты нуждаются в обновлении

## 🎯 Коды причин блокировки (11 типов)

| Код | Текст | Иконка | Категория |
|-----|-------|--------|-----------|
| `PROJECT_STATUS_NOT_STARTABLE` | Статус проекта не допускает старт | 🚫 | Критично |
| `PROJECT_ON_HOLD` | Проект на удержании (on hold) | ⏸️ | Предупреждение |
| `NO_TASKS` | Нет задач в проекте | 📝 | Критично |
| `ALL_TASKS_BLOCKED` | Все задачи недоступны для старта | 🔒 | Критично |
| `NO_ESTIMATES` | Нет смет | 💰 | Критично |
| `NO_STARTABLE_ITEMS_IN_ESTIMATES` | В сметах нет позиций для старта | 📊 | Критично |
| `MISSING_ASSIGNMENT` | Нет назначенного исполнителя/команды | 👤 | Критично |
| `MISSING_PERMISSIONS` | Недостаточно прав для старта | 🔐 | Критично |
| `DEPENDENCIES_NOT_MET` | Не выполнены зависимости/предусловия задач | 🔗 | Критично |
| `BUDGET_OR_APPROVAL_REQUIRED` | Требуется бюджет/подтверждение клиента | ✅ | Предупреждение |
| `COMPLIANCE_HOLD` | Стоп по соответствию (permit/COI и др.) | 📋 | Критично |
