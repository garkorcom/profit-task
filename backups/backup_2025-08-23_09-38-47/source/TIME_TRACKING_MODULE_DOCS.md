# 📊 Документация модуля учета рабочего времени

## 🎯 Обзор
Модуль учета времени позволяет сотрудникам отслеживать время работы над задачами в проектах, автоматически сохранять отработанные часы в табель и формировать отчеты.

## 🏗️ Архитектура

### 1. Основные компоненты

#### TimeTrackingContext (`src/contexts/TimeTrackingContext.tsx`)
**Назначение:** Центральное управление состоянием учета времени во всем приложении.

**Функции:**
- `startWork()` - начать учет времени для задачи
- `stopWork()` - завершить работу и сохранить в табель
- `pauseWork()` - поставить учет на паузу
- `resumeWork()` - возобновить учет

**Состояние:**
- `isWorking` - идет ли сейчас учет времени
- `currentSession` - текущая рабочая сессия (проект, задача, время начала)
- `elapsedSeconds` - количество секунд с начала работы
- `isPaused` - на паузе ли учет

**Связи с Firebase:**
- Обновляет статус задачи в коллекции `tasks`
- Сохраняет записи в коллекцию `timesheetEntries`
- Загружает фото в Firebase Storage (опционально)

#### TimeTrackingButton (`src/components/TimeTrackingButton.tsx`)
**Назначение:** Универсальная кнопка для начала учета времени.

**Особенности:**
- Работает на любой странице без перенаправлений
- Пошаговый интерфейс (Stepper)
- Загрузка проектов и задач в реальном времени

**Используется на страницах:**
- HomePage - главная страница
- TasksPage - страница задач
- EmployeesPage - страница сотрудников

#### TimeTrackingPage (`src/pages/TimeTrackingPage.tsx`)
**Назначение:** Отдельная страница для управления учетом времени.

**Функционал:**
- Отображение активной рабочей сессии
- Статистика по проектам и задачам
- Список доступных проектов
- Кнопки управления (пауза, стоп)

**URL:** `/time-tracking`

#### ActiveWorkSession (`src/components/ActiveWorkSession.tsx`)
**Назначение:** Карточка активной рабочей сессии.

**Отображает:**
- Название проекта и задачи
- Таймер с отсчетом времени
- Кнопки паузы и завершения работы
- Градиентный дизайн для привлечения внимания

**Используется на:** HomePage

### 2. API и хранение данных

#### Firestore коллекции:

**`users/{userId}/tasks`**
```typescript
{
  id: string;
  name: string;
  projectId: string;
  status: 'pending' | 'in_progress' | 'completed';
  startedAt?: Date;          // Когда начата работа
  startPhotoUrl?: string;    // Фото начала работ
  startLocation?: {          // Геолокация
    latitude: number;
    longitude: number;
  };
}
```

**`users/{userId}/timesheetEntries`**
```typescript
{
  id: string;
  employeeId: string;        // ID сотрудника
  employeeName: string;      // Имя сотрудника
  projectId: string;         // ID проекта
  projectName: string;       // Название проекта
  date: string;             // Дата в формате YYYY-MM-DD
  hours: number;            // Отработанные часы
  description: string;      // Описание работы
  createdAt: Timestamp;     // Когда создана запись
  createdBy: string;        // Кто создал запись
}
```

#### LocalStorage:
**`workSession`** - сохраняет активную сессию для восстановления после перезагрузки
```json
{
  "taskId": "abc123",
  "taskName": "Разработка интерфейса",
  "projectId": "proj456",
  "projectName": "Веб-приложение",
  "startTime": "2024-01-15T10:30:00.000Z"
}
```

```

```

### 4. Поток данных

1. **Начало работы:**
   - Пользователь нажимает кнопку → открывается диалог
   - Выбирает проект → загружаются задачи проекта
   - Выбирает задачу → подтверждение
   - TimeTrackingContext.startWork() →
     - Обновляет задачу в Firebase
     - Сохраняет сессию в localStorage
     - Запускает таймер

2. **Во время работы:**
   - Таймер обновляется каждую секунду
   - Данные хранятся в контексте и localStorage
   - При перезагрузке страницы сессия восстанавливается

3. **Завершение работы:**
   - Пользователь нажимает "Завершить"
   - TimeTrackingContext.stopWork() →
     - Рассчитывает отработанные часы
     - Создает запись в timesheetEntries
     - Очищает сессию из localStorage
     - Сбрасывает таймер

## 🔧 Технические детали

### Зависимости:
- React Context API для управления состоянием
- Firebase Firestore для хранения данных
- Firebase Storage для фото (опционально)
- localStorage для персистентности
- Material-UI для интерфейса

### Безопасность:
- Все данные привязаны к userId
- Firestore Rules ограничивают доступ
- Проверка аутентификации на каждом уровне

### Производительность:
- Ленивая загрузка проектов и задач
- Оптимизированные запросы к Firestore
- Локальное кеширование активной сессии
- Отписка от стримов при размонтировании

## 🚀 Использование

### Для разработчиков:

```typescript
// Использование в компоненте
import { useTimeTracking } from '../contexts/TimeTrackingContext';

const MyComponent = () => {
  const { isWorking, startWork, stopWork } = useTimeTracking();
  
  // Начать работу
  await startWork(projectId, projectName, taskId, taskName);
  
  // Завершить работу
  await stopWork();
};
```

### Для пользователей:

1. **Начать работу:**
   - Нажать "Начать зарабатывать" на любой странице
   - Выбрать проект и задачу
   - Подтвердить начало работы

2. **Контроль времени:**
   - Таймер отображается на главной странице
   - Можно поставить на паузу
   - Время сохраняется при перезагрузке

3. **Завершить работу:**
   - Нажать "Завершить работу"
   - Время автоматически сохранится в табель
   - Можно посмотреть в разделе "Сотрудники" → "Табель"

## 📈 Отчетность

Табель доступен в нескольких местах:
- **По сотруднику:** `/employees/{id}/timesheet`
- **По проекту:** `/projects/{id}` (вкладка Табель)
- **API для экспорта:** `getTimesheetsByEmployeeStream`, `getTimesheetsByProjectStream`
