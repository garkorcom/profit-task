## 🎯 КЛЮЧЕВЫЕ ВОЗМОЖНОСТИ ERP

### 📦 **Унифицированная номенклатура**
- **Товары** (`ProductItem`) - с складским учетом, партиями, сроками
- **Услуги** (`ServiceItem`) - без складских операций, с нормативами времени
- **Комплекты** (`BundleItem`) - составные элементы с компонентами

### 🏪 **Складская система**
- **Партийный учет** - каждая партия с датой, стоимостью, сроком годности
- **FIFO/WAC методы** - алгоритмы оценки запасов
- **Резервирование** - под сметы, проекты, заказы
- **Инвентаризации** - с корректировками и причинами

### 🔗 **Интеграция со сметами**
- **Автоматическое резервирование** материалов под утвержденные сметы
- **Контроль остатков** при добавлении материалов в смету
- **Выдача материалов** на проекты с трекингом потребления
- **Анализ отклонений** план vs факт по материалам
