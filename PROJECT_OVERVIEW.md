# My Business App - ERP система управления проектами

## 📋 Обзор проекта

**My Business App** - это современная веб-платформа для управления бизнес-процессами, построенная на React и Firebase. Система предоставляет комплексные инструменты для управления проектами, отслеживания времени, составления смет, работы с контрагентами и управления складскими запасами.

## 💼 ERP модуль - Финансовый учет

### COGS (Cost of Goods Sold) система

**Критически важный модуль** для автоматического расчета себестоимости:

#### Include_Mode логика
- **NONE** - время логируется, но не влияет на COGS (административные задачи)
- **COGS** - создает записи прямых трудозатрат без накладных расходов
- **OH (Overhead)** - полные затраты с применением burden factor и накладных расходов

#### Безопасность финансовых данных
- **Cloud Functions** - все расчеты происходят на защищенном бэкенде
- **Security Rules** - блокировка клиентских изменений финансовых записей
- **Аудит трейл** - полная история всех финансовых операций
- **Историчность ставок** - CostSnapshot сохраняет точку расчета

#### Расчет трудозатрат
```typescript
// Формула расчета полной стоимости
const baseCost = hours * hourlyRate;
const overtimeCost = overtimeHours * hourlyRate * overtimeMultiplier;
const totalCost = (baseCost + overtimeCost) * burdenFactor;
```

### Система ставок (Labor Rates)

**Гибкая система оплаты:**
- Персональные ставки для сотрудников
- Ролевые ставки по умолчанию
- Проектные ставки для специфичных задач
- Исторические ставки с датами действия
- Множители для переработок (1.5x, 2.0x)
- Burden Factor для накладных расходов (обычно 1.2-1.5)

### Валидация времени

**Строгий контроль временных записей:**
- Минимальная запись: 0.25 часа
- Автоматическое округление вверх
- Дневной лимит: 12 часов (настраивается по ролям)
- Недельный лимит: 72 часа
- Cut-off время: пятница 18:00 (после блокировка изменений)
- Backdate лимит: 14 дней для обычных пользователей
