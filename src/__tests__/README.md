## Особенности реализации

### Моки
- **Firebase**: Полностью замокирован, включая Firestore операции
- **Геолокация**: Мокированы `navigator.geolocation` методы  
- **React Router**: Мокированы навигационные функции
- **API функции**: Все API вызовы заменены на моки с синхронными callbacks

### TestWrapper
Предоставляет необходимую инфраструктуру для тестов:
- Material-UI Theme Provider
- React Router (BrowserRouter)
- TimeTrackingProvider (мокированный)

### Стратегия тестирования
1. **Компонентное тестирование**: Каждый компонент тестируется изолированно
2. **Мокирование зависимостей**: Все внешние зависимости заменены на моки
3. **Интеграционное тестирование**: Проверка взаимодействия между компонентами
4. **Упрощенные моки страниц**: Для страниц используются простые моки без сложной логики

## Запуск тестов

```bash
# Запуск всех тестов компонентов времени
npm test -- --testPathPattern=timeComponents.test.tsx

# Запуск в режиме наблюдения
npm test -- --testPathPattern=timeComponents.test.tsx --watch

# Запуск с подробным выводом
npm test -- --testPathPattern=timeComponents.test.tsx --verbose
```
